Built for the scroll

Each panel animates against its own position in the viewport. No observer, no listener, no JavaScript at all.

  1. 01

    Native timeline

    The browser drives the animation from scroll position with animation-timeline: view().

  2. 02

    Runs off thread

    Because it is declarative, the compositor can run it without waking the main thread.

  3. 03

    Degrades cleanly

    Where the timeline is unsupported, every panel is simply visible. Nothing is hidden behind a script.

  4. 04

    Respects the setting

    Reduced motion removes the movement and keeps the content exactly where it belongs.
