Vertical in, horizontal out

Scrolling this box down drives the strip sideways. The browser maps one axis onto the other with no script listening for anything.

Runs off the main thread

A declarative timeline can be handed to the compositor, so the pan holds its frame rate while the page is busy elsewhere.

03

Self-contained

The timeline is named on this container, not on the document, so the section behaves the same inside a preview frame as it does full width.

04

Nothing hidden behind support

Where scroll timelines are unavailable the strip stays a plain horizontal scroller. Every panel is reachable either way.
